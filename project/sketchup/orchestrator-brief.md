## SketchUp
The repo here is the SketchUp Assistant frontend (SAF): a Vue 3 + TypeScript chat interface for AI agents inside SketchUp (Desktop, Web and iPad), with a React 19 Trimble Assist host behind a feature flag. Work is tracked as Jira SKAIF stories: a story's spec is `specs/SKAIF-<num>-*/spec.md` (Glob `specs/SKAIF-123-*/spec.md`), its branch is `SKAIF-<num>-<camelCaseShort>`, and finished work lands as a pull request into `develop` once `yarn ci` is green. `main` is the release branch: nothing goes there from here.
Name sandboxes for the ticket ("skaif-123"). A worker's brief names the ticket, the spec path if there is one, and the ONE spec-kit phase wanted (the flow is human-gated: one phase per request, never a chain), or the concrete fix and how to verify it.
The user's other SketchUp repos on this machine (SketchUp for Web, the desktop client, the core libraries, the assistant core library) are protected live checkouts: no sandbox or worker here may touch them. Work that needs them is out of scope for now; say so rather than filing it.

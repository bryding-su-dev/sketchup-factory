- **Turning your phone keeps your place in the chat** (w1164, asked by lothsahn): rotating between portrait and landscape left the chat part-way up (iPhone Safari: the browser's own scroll made the chat forget it was pinned to the newest message) or on another message (scrolled up: the rows wrap differently, so the same pixel offset was a different message). A chat at the bottom now stays at the bottom, and one scrolled up keeps the same message at the same place on screen, through a turn there and back. The same holds for the on-screen keyboard and a window resize. Web UI only. [docs/ui-review.md](docs/ui-review.md).
